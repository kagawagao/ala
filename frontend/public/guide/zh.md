# ALA 使用指南

ALA（Android Log Analyzer）是一款 AI 驱动的全栈工具，用于分析 Android logcat 输出与 Perfetto Trace。  
**版本 2.2.2**

---

## 快速开始

1. **打开文件** – 点击上传面板、将文件拖放到主区域，或在上传区域下方的路径输入框中直接输入本地文件或目录路径。  
   支持格式：`.log`、`.txt`、`.gz`、`.zip`（logcat），`.pb`、`.json`（Perfetto Trace）。
2. **应用过滤器** – 在侧边栏设置时间范围、关键词、日志级别、标签、PID 或 TID，然后点击**应用过滤器**更新视图。
3. **切换视图** – 在**日志分析**与 **Trace 分析**标签之间切换查看结果。
4. **选择项目** – 可在顶栏下拉框中选择项目，为 AI 助手提供源码上下文。

---

## 日志分析

- 通过拖放或文件选择器上传一个或多个 `.log`、`.txt`、`.gz` 或 `.zip` 文件，也可在上传区域下方的路径输入框中直接输入本地文件或目录路径。
- 使用**侧边栏过滤器**缩小结果范围：
  - **关键词** – 支持正则表达式。
  - **日志级别** – Verbose、Debug、Info、Warning、Error、Fatal。
  - **标签** – 支持正则表达式。
  - **时间范围**、**PID**、**TID** – 可选精确匹配字段。
- **过滤预设** – 保存常用过滤组合，方便随时复用。选中项目时保存到项目，否则全局保存。
- **自动换行** – 切换长日志行的换行显示模式。
- **高亮** – 在不改变日志集合的前提下，对关键词进行视觉标记。
- **导出** – 将过滤后的日志条目下载为 CSV（RFC 4180，含 BOM）或 JSON。

---

## Trace 分析

- 上传 Perfetto Trace 文件（`.pb` 或 `.json`）。
- 查看 **Trace 摘要**：持续时间、进程数、线程数、主要切片、FTrace 事件及元数据。
- 通过**进程过滤**按进程名（正则，不区分大小写）或 PID 列表筛选数据。
- 使用 **SQL 查询**（Python Perfetto API）对 Trace 运行自定义查询以进行高级分析。

---

## AI 助手

1. **配置 AI** – 点击顶栏的**模型管理**（方格图标），输入 API 端点、密钥和模型名称。  
   ALA 支持 Anthropic Claude、OpenAI 及任何兼容 OpenAI 接口的服务商。可添加自定义模型，启用/禁用，并配置扩展思考功能。
2. **提问** – 在右侧 AI 聊天面板中输入问题，助手可分析已过滤日志、已加载 Trace 数据及本地文件/目录内容。
3. **代理模式** – 开启代理模式，让 AI 主动查询日志概览、搜索条目、检查 Trace 进程并可对 Trace 执行 SQL 查询。
4. **附加上下文** – 通过上下文选择器将助手聚焦于日志、Trace、本地文件、本地目录或通用问题。
5. **惰性本地分析** – 将 ALA 指向本地文件或目录路径，AI 代理通过流式工具按需探索日志：无需上传，无文件大小限制。
6. **扩展思考** – 启用「思考模式」（Anthropic），使用可配置的 Token 预算进行更深层推理。

---

## 项目管理

项目用于注册本地源码目录，让 AI 助手结合代码进行更精准的分析。

1. 打开**项目设置**（顶栏文件夹图标）。
2. 点击**添加项目**，输入名称及 Android 源码目录的绝对路径。
3. 在顶栏下拉框中选择该项目以激活。
4. 项目内的**上下文文档**（`AGENTS.md`、`CLAUDE.md`、`.github/copilot-instructions.md` 等）将自动注入 AI 上下文。
5. 使用**初始化过滤器** / **更新过滤器**，根据项目的日志模式自动生成过滤预设（基于 ripgrep，比纯 Python 快 265 倍）。

---

## 使用建议

- **过滤预设**在选中项目时保存到项目，否则保存至浏览器 `localStorage`。
- **后端必须运行**，前端才能连接。若状态标签显示「未连接」，请先启动 Python 后端。
- API Key **存储在浏览器本地**（`localStorage`），并在发送 AI 请求时传输至 ALA 后端以转发给所配置的 AI 服务商。除您配置的服务商外，Key 不会发送给任何第三方。
- 日志文件以流式方式传输至后端，超大文件内容将逐步显示。
- 使用**导出**按钮（CSV 或 JSON）将过滤后的日志条目下载以供进一步处理。
- 版本号显示在顶栏中 — 反馈问题时便于提供。
