# ALA 使用指南

ALA（Android Log Analyzer）是一款 AI 驱动的全栈工具，用于分析 Android logcat 输出、Perfetto Trace、网络抓包（PCAP）以及蓝牙 HCI 日志。

---

## 快速开始

1. **打开文件** – 点击上传面板、将文件拖放到主区域，或在上传区域下方的
   路径输入框中直接输入本地文件或目录路径。
   支持格式：`.log`、`.txt`、`.gz`、`.zip`（logcat），`.pb`、`.json`
   （Perfetto Trace），`.pcap`、`.pcapng`（网络抓包），`.hci`、`.btsnoop`、
   `.cfa`（蓝牙 HCI）。
2. **应用过滤器** – 按 `Ctrl+K`（macOS 按 `Cmd+K`）打开右侧过滤抽屉，
   设置条件后点击**应用过滤器**更新视图。
3. **切换视图** – 在**日志分析**、**Trace 分析**、**PCAP 分析**与**蓝牙 HCI** 标签之间切换查看结果。
4. **选择项目** – 可在顶栏下拉框中选择项目，为 AI 助手提供源码上下文。
5. **配置 AI 模型** – 在顶栏模型选择器中切换当前使用的 AI 模型，或进入模型管理页面添加自定义模型。

---

## 日志分析

- 通过拖放或文件选择器上传一个或多个 `.log`、`.txt`、`.gz` 或 `.zip` 文件，也可在上传区域下方的路径输入框中直接输入本地文件或目录路径。
- 文件上传后进入**待加载**状态，AI 代理按需加载文件进行解析，无需预先完整解析。
- 打开**过滤抽屉**（`Ctrl+K`）缩小结果范围：
  - **关键词** – 支持正则表达式，可选 AND/OR 运算符模式。
  - **日志级别** – Verbose、Debug、Info、Warning、Error、Fatal。
  - **标签** – 支持正则表达式，可快速选择热门标签。
  - **时间范围** – 格式：`MM-DD HH:mm:ss.SSS`。
  - **PID**、**TID** – 可选精确匹配字段。
- **过滤预设** – 保存常用过滤组合，方便随时复用。选中项目时保存到项目，否则全局保存。
- **自动换行** – 切换长日志行的换行显示模式。
- **高亮** – 在不改变日志集合的前提下，对关键词进行视觉标记。
- **导出** – 将过滤后的日志条目下载为 CSV（RFC 4180，含 BOM）或 JSON。
- **惰性加载** — 日志文件上传至临时存储，按需流式过滤。大型文件逐步加载，不阻塞界面。

## Trace 分析

- 上传 Perfetto Trace 文件（`.pb` 或 `.json`）。
- 查看 **Trace 摘要**：持续时间、进程数、线程数、主要切片、FTrace 事件及元数据。
- 通过**进程过滤**按进程名（正则，不区分大小写）或 PID 列表筛选数据。
- 在 AI 聊天中使用 **SQL 查询**（Python Perfetto API）对 Trace 运行自定义查询以进行高级分析。

---

## PCAP 分析

- 上传一个或多个网络抓包文件（`.pcap` 或 `.pcapng`）。
- 查看**数据包详情**：包序号、时间戳、协议、源/目标 IP 和端口、TCP 标志、载荷长度。
- 浏览**协议分布**，查看各协议占比（TCP、UDP、ICMP 等）。
- 应用 **PCAP 过滤器**：
  - **协议** – 按特定协议筛选。
  - **源 IP / 目标 IP** – IP 地址匹配。
  - **源端口 / 目标端口** – 端口号匹配。
  - **TCP 标志** – 按 TCP 标志组合（SYN、ACK、FIN、RST 等）筛选。
- **惰性加载** — PCAP 文件上传至临时存储，按需流式过滤。大型抓包文件逐步加载，不阻塞界面。
- **统计信息** — 唯一 IP 数、连接总数及协议分布由服务端计算，性能更优。

---

## 蓝牙 HCI 分析

- 上传一个或多个蓝牙 HCI 日志文件（`.hci`、`.btsnoop`、`.cfa`），同时支持 `.gz` 和 `.zip` 压缩包。
- 查看**数据包详情**：包序号、时间戳、方向（Host→Controller 或 Controller→Host）、HCI 类型（Command、Event、ACL Data、SCO Data、ISO Data）、操作码/事件码及解码名称、数据长度。
- 浏览**摘要统计**：总包数、方向分布（Host→Controller vs Controller→Host）、HCI 类型分布、唯一操作码数、捕获时长。
- 应用 **HCI 过滤器**：
  - **方向** – Host→Controller 或 Controller→Host。
  - **HCI 类型** – Command、Event、ACL Data、SCO Data、ISO Data。
  - **操作码 / 操作码名称** – 按 HCI 命令操作码（十六进制或十进制）或解码名称筛选。
  - **事件码 / 事件名称** – 按 HCI 事件码（十六进制或十进制）或解码名称筛选。
  - **关键词** – 对数据包摘要进行全文搜索。
- **惰性加载** — HCI 文件上传至临时存储，按需流式过滤。大型日志文件逐步加载，不阻塞界面。
- **操作码/事件解码** — HCI 命令操作码和事件码自动解码为可读名称（如 `0x0C01` → "LE Set Advertising Data"，`0x3E` → "LE Meta Event"）。
- **统计信息** — 方向分布、HCI 类型占比及唯一操作码统计由服务端计算。

## AI 助手

1. **配置 AI** – 点击顶栏的**模型管理**（方格图标），浏览内置模型或添加自定义模型。
   ALA 支持 Anthropic Claude、OpenAI 及任何兼容 OpenAI 接口的服务商。每个模型可独立配置 API 端点、密钥、温度和思考模式。可在顶栏模型选择器中快速切换当前使用的模型。
2. **提问** – 在右侧 AI 聊天面板中输入问题，助手可分析已过滤日志、已加载 Trace、PCAP/HCI 数据及本地文件/目录内容。
3. **代理模式** – 开启代理模式，让 AI 主动查询日志概览、搜索条目、检查 Trace 进程、对 Trace 执行 SQL 查询以及筛选 PCAP/HCI 数据包。
4. **附加上下文** – 通过上下文选择器将助手聚焦于日志、Trace、PCAP、HCI、本地文件、本地目录或通用问题。
5. **惰性本地分析** – 将 ALA 指向本地文件或目录路径，AI 代理通过流式工具按需探索日志：无需上传，无文件大小限制。
6. **扩展思考** – 为支持扩展思考的模型（如 Claude）启用「思考模式」，使用可配置的 Token 预算进行更深层推理。支持三种模式：关闭、自动（隐藏过程）、开启（显示思考过程）。
7. **下载对话** – 点击聊天面板中的下载按钮，将完整对话导出为 Markdown 文件。

## 项目管理

项目用于注册本地源码目录，让 AI 助手结合代码进行更精准的分析。

1. 打开**项目设置**（顶栏文件夹图标）。
2. 点击**添加项目**，输入名称及 Android 源码目录的绝对路径。
3. 在顶栏下拉框中选择该项目以激活。
4. 项目内的**上下文文档**（`AGENTS.md`、`CLAUDE.md`、`.github/copilot-instructions.md` 等）将自动注入 AI 上下文。
5. 使用**初始化过滤器** / **更新过滤器**，根据项目的日志模式自动生成过滤预设（基于 ripgrep，比纯 Python 快 265 倍）。

---

## 模型管理

1. 打开**模型管理**页面（顶栏方格图标）。
2. **内置模型** — 浏览预置的常见 AI 模型，点击即可自动填充配置字段。
3. **自定义模型** — 添加任意兼容 OpenAI 接口的模型，配置显示名称、模型 ID、API 端点、提供商标识以及是否支持扩展思考。
4. **激活/停用** — 点击开关控制模型是否出现在顶栏模型选择器中。只有已激活且配置了 API Key 的模型才会显示。
5. **模型选择器** — 在主页顶栏可直接切换当前使用的 AI 模型，无需进入管理页面。
6. **API Key** — 每个模型的 API Key 单独存储在浏览器本地（`localStorage`），不会同步至后端。

---

## 系统设置

1. 打开**系统设置**页面（顶栏齿轮图标），配置应用级全局参数。
2. 当前支持配置默认文件下载路径等选项，后续版本将持续扩展更多设置项。

## 使用建议

- **过滤预设**在选中项目时保存到项目，否则保存至浏览器 `localStorage`。
- **后端必须运行**，前端才能连接。若状态标签显示「未连接」，请先启动 Python 后端。
- API Key **存储在浏览器本地**（`localStorage`），发送 AI 请求时传输至 ALA 后端以转发给所配置的 AI 服务商。除您配置的服务商外，Key 不会发送给任何第三方。
- 日志文件以流式方式传输至后端，超大文件内容将逐步显示。
- 文件上传后进入**待加载**状态，AI 代理可按需解析文件，避免不必要的预处理。
- PCAP 与 HCI 文件均采用惰性加载：上传至临时路径后按需过滤，应用过滤器前不会完整解析整个文件。
- 使用**导出**按钮（CSV 或 JSON）将过滤后的日志条目下载以供进一步处理。
- 版本号显示在顶栏中 — 反馈问题时便于提供。
